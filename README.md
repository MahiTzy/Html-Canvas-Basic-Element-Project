# HTML Canvas Basic Elements

A small web project for exploring drawing primitives and rendering with the HTML Canvas API.

## Overview
The project provides a practical starting point for experimenting with canvas-based graphics in the browser.

## Technology
- HTML
- JavaScript
- HTML Canvas API

## Getting Started
```bash
git clone https://github.com/MahiTzy/Html-Canvas-Basic-Element-Project.git
cd Html-Canvas-Basic-Element-Project
```
Open the main HTML file in a modern browser. If the project uses modules or local resources that require HTTP, run a local static server from the project directory.

## Usage
Explore the canvas implementation and adjust the drawing instructions to experiment with shapes, coordinates, colors, and rendering behavior.

## Development
Update the HTML or JavaScript source and refresh the browser to see the result.
